# zapret2 for Innbox G84

Установка `zapret2/nfqws2` на Innbox G84 с операторской прошивкой — без OpenWrt
и без перепрошивки.

> [!WARNING]
> Это не официальный проект Iskratel/Innbox или bol-van. Используйте только на
> своём оборудовании и заранее сохраните конфигурацию роутера.

## Что проверено

- Innbox G84, EcoNet EN7528 / MIPS32r2 little-endian;
- Linux 3.18.21 и `iptables/ip6tables` 1.4.21;
- IPv4/IPv6 NFQUEUE;
- постоянное хранение в `/var/SaaS` (JFFS2);
- автозапуск через штатные `appmgrd`, `csmconf` и `csmctl`;
- восстановление правил после пересборки операторского firewall;
- работа вместе с аппаратным NAT `mt_whnat`;
- установка с нуля, удаление, повторная установка и запуск после reboot.

Проверенный профиль обрабатывает TCP 80/443 через OOB и QUIC/UDP 443 через
поддельный QUIC Initial. На тестовом устройстве после reboot работали YouTube,
Discord, Instagram, X и Rutracker. Результат зависит от провайдера и текущей
конфигурации DPI.

## Быстрый старт

Скачайте два файла из последнего Release в одну папку:

- `g84-zapret2.sh`;
- `g84-zapret2-payload.tar.gz`.

Затем:

```bash
chmod +x g84-zapret2.sh
./g84-zapret2.sh diagnose
./g84-zapret2.sh install --dry-run
./g84-zapret2.sh install
```

По умолчанию используется `superadmin@192.168.1.1`. Старый SSH-сервер G84 может
запросить пароль несколько раз; установщик его не сохраняет.

Проверка состояния:

```bash
./g84-zapret2.sh status
./g84-zapret2.sh verify
```

Удаление с предварительным резервным копированием:

```bash
./g84-zapret2.sh uninstall
```

Другой адрес роутера:

```bash
./g84-zapret2.sh diagnose --host 192.168.1.254
```

Обычная установка ждёт исчезновения и возвращения SSH после reboot, затем
автоматически запускает `verify`. `--no-reboot` применяет изменения сразу и
проверяет текущий запуск, но явно предупреждает, что persistence не проверена.

WAN определяется по default route; его можно переопределить через `--wan nas1`
или `G84_WAN`.

## Как это работает

Скрипт проверяет модель, UID 0, NFQUEUE и свободное место, создаёт резервные
копии, передаёт статический `linux-mipsel` бинарник и Lua-библиотеки в
`/var/SaaS/zapret2`, добавляет безопасные NFQUEUE-правила с `--queue-bypass` и
регистрирует два процесса в конфигурационной базе `appmgrd`.

Payload и installer имеют общую версию `0.2.0`; SHA-256 проверяется по
`manifest.env` до любых изменений. Установка использует staging в RAM и
временный `zapret2.old`, а `appmgr`-слоты выбираются без жёсткой привязки к 1/2 и
записываются в `appmgr-slots` для безопасного удаления.

`watch-rules.sh` восстанавливает правила, если операторская прошивка пересоздаёт
firewall. Каталог-блокировка защищает от одновременного изменения таблиц двумя
процессами. Аппаратный NAT не отключается.
