# zapret2 для Innbox G84

Установка и управление **zapret2 / nfqws2** на Innbox G84 со штатной операторской
прошивкой. Проект включает установщик, адаптивные стратегии обработки трафика
и интеграцию с автозапуском роутера.

## Возможности

- Автоматическое переключение стратегий TCP и QUIC при признаках блокировки.
- Независимый подбор для каждого домена, устройства и семейства IP.
- Настраиваемые списки обрабатываемых доменов и исключений.
- Автозапуск и восстановление правил после обновления firewall.
- Проверка совместимости, контрольных сумм и резервное копирование при установке.

## Совместимость

Проект предназначен для **Innbox G84 со штатной прошивкой**. Для установки
необходим SSH-доступ с правами администратора. На компьютере требуются Bash
и OpenSSH.

### Что проверено

- Установка и управление сервисом на Innbox G84.
- Обработка трафика IPv4 и IPv6.
- Работа адаптивных стратегий на реальном оборудовании.

Доступность отдельных сервисов зависит от сети провайдера и конфигурации DPI.
Подробности совместимости и проверки приведены в [документации](docs/compatibility.md).

## Установка

Скачайте из [последнего релиза](https://github.com/Abobus11009/innbox-g84-zapret2/releases/latest)
следующие файлы и поместите их в одну папку:

- `g84-zapret2.sh` — установщик;
- `g84-zapret2-payload.tar.gz` — пакет для роутера;
- `manifest.env` — версия и контрольная сумма пакета.

Выполните диагностику и предварительную проверку:

```bash
chmod +x g84-zapret2.sh
./g84-zapret2.sh diagnose
./g84-zapret2.sh install --dry-run
```

Затем запустите установку:

```bash
./g84-zapret2.sh install
```

По умолчанию используется адрес `superadmin@192.168.1.1`. Пароль запрашивается
интерактивно и не сохраняется установщиком. Для другого адреса добавьте
`--host`, например:

```bash
./g84-zapret2.sh install --host 192.168.1.254
```

Обычная установка включает перезагрузку и последующую проверку автозапуска.
Параметр `--no-reboot` позволяет применить изменения без перезагрузки; проверку
запуска после загрузки роутера в этом случае нужно выполнить отдельно.

При обновлении существующие `config`, `hosts.txt` и `hosts-exclude.txt`
сохраняются. Параметр `--wan` явно меняет WAN; при недоступном IPv6 NFQUEUE
установщик отключает IPv6. Ошибка переноса настроек прерывает обновление
до остановки старой версии.

## Управление

| Команда | Назначение |
|---|---|
| `./g84-zapret2.sh diagnose` | Диагностика платформы и сети |
| `./g84-zapret2.sh status` | Состояние сервиса и правил |
| `./g84-zapret2.sh verify` | Процессы, владелец NFQUEUE и все правила IPv4/IPv6 |
| `./g84-zapret2.sh recover` | Восстановление после прерванной установки |
| `./g84-zapret2.sh uninstall` | Удаление с резервным копированием |

## Настройка стратегий

Стратегии применяются к доменам из `router/hosts.txt`. Исключения задаются
в `router/hosts-exclude.txt` и имеют приоритет. Поддомены включаются автоматически.

Стратегии переключаются по признакам неудачного соединения. Выбранный вариант
хранится в памяти процесса и сбрасывается при его перезапуске. Подробное описание
настройки и диагностики: [адаптивные стратегии](docs/adaptive.md).

Пакеты TCP 80/443 и UDP 443 попадают в NFQUEUE до проверки домена. Исключение
домена отключает стратегии, но сохраняет расходы на обработку очереди.
Замеры и ограничения описаны в [документации по производительности](docs/performance.md).

## Резервные копии

Установщик сохраняет резервные копии в локальную папку `backups/`. Они могут
содержать приватную конфигурацию роутера. Не публикуйте эту папку, журналы
диагностики и данные подключения.
