# 0.4.0

Мастер установки для Windows, macOS и Linux: поиск Innbox G84 в локальной
сети, получение superadmin из поддерживаемого экспорта конфигурации,
встроенный SSH-клиент с поддержкой старых алгоритмов. Готовый пакет включён
в приложение; сборки выпускаются GitHub Actions.

Исправлены хранение комплектов резервных копий и пробный запуск без изменения
firewall. Netcat требуется только для терминальной установки с reboot.
Удаление теперь использует журнал и восстанавливает файлы, регистрацию,
процессы и правила при сбое; дополнительные поля appmgr сохраняются.

Добавлены проверки ошибок удаления, состояния подключения мастера,
неоднозначной карты слотов и хранения резервных копий. Пользовательские
настройки обновления сохраняются.

Получение доступа зависит от прошивки; автоматический сброс роутера не
выполняется. Доменное исключение по-прежнему не устраняет расходы NFQUEUE.
