# Innbox G84 zapret2 0.4.2

Основной мастер теперь распространяется как один `g84-setup.py` со встроенными
веб-интерфейсом и пакетом для роутера. Нужны Python 3.10+ и зависимости из
`requirements.txt`; отдельные сборки приложения больше не выпускаются.
Все операции прежнего мастера сохранены. Перезагрузка по умолчанию отключена,
параметр reboot принимает только логическое значение.

Исправлены ошибки предварительной проверки (перезапись рабочего PID/журнала),
выбора дублированных слотов appmgr, потери дополнительных полей свободного слота
при откате и преждевременного отката при временном сбое SSH во время reboot.
Оба мастера защищают экспорт конфигурации закрытым каталогом до создания XML:
на G84 `csmconf` игнорирует umask и создаёт файл с правами 0644.

Добавлены регрессионные тесты и проверки самостоятельного Python-скрипта.
На G84 проведены изолированные проверки без перезагрузки и смены рабочих правил.
Полное обновление работающего роутера и автозапуск после reboot не проверялись.
