# Первый доступ и мастер установки

Мастер `g84-setup` содержит пакет для роутера, SSH-клиент и расшифровщик
старого экспорта конфигурации. Bash, OpenSSH, netcat и OpenSSL на компьютере
для него не нужны. Интерфейс открывается в браузере на случайном порту
`127.0.0.1`; управление требует одноразовый токен. Интернет для настройки
не требуется. Пароли остаются в памяти приложения; конфигурации и SSH-ключи
сохраняются локально в каталоге, указанном в интерфейсе.

## Порядок работы

1. Подключитесь к домашней сети. Запустите файл для своей ОС и архитектуры.
2. Нажмите «Найти роутер» или введите его локальный IPv4.
3. Укажите пароль веб-интерфейса (обычно пользователь `admin`). Нажмите
   «Подготовить доступ». Альтернатива — импорт экспортированной конфигурации
   либо ввод уже известного пароля superadmin.
4. Проверьте совместимость и установите пакет. При обновлении сохраняются
   пользовательские настройки и списки доменов. По умолчанию выполняется
   перезагрузка с проверкой автозапуска.

Поиск рассматривает шлюзы и соседей локальной сети, максимум 16 адресов.
Он подтверждает модель по веб-интерфейсу; полного сканирования подсети нет.
При VPN или нестандартной топологии введите адрес вручную.

Когда работа завершена, нажмите «Закрыть мастер», чтобы завершить локальное
приложение и закрыть SSH-соединение.

## Получение superadmin

Метод основан на опубликованном исследовании
[старого экспорта Innbox G84](https://internet-lab.ru/innbox_g84_superadmin).
На поддерживаемой форме мастер входит обычной веб-учётной записью, получает
`config_old_tl.xgi` и разбирает запись superadmin. Старый формат использует
AES-256-CBC с ключом, производным от `InnboxG84`, соли и MD5; совместимость
формата описана в [документации OpenSSL](https://docs.openssl.org/master/man1/openssl-enc/).
Обрабатываются также XML и gzip-экспорты.

Это восстановление пароля из доступного владельцу экспорта, а не универсальный
способ для любой прошивки. Если экспорт отключён, формат изменён или пароль
веб-интерфейса неизвестен, мастер останавливается. Автоматического сброса,
перебора паролей и изменения операторских настроек нет. При временной
блокировке веб-входа нужно дождаться её окончания.

## SSH

Если SSH уже отвечает, настройки доступа не меняются. Для известной формы
[управления доступом G84](https://internet-lab.ru/innbox_g84_ssh) мастер может
добавить SSH на LAN, порт 22, только с IPv4 этого компьютера (/32).
Неизвестная форма или неоднозначная таблица доступа прекращают настройку.
Если запись добавлена, но SSH не отвечает, интерфейс сообщает об этом;
её можно проверить и удалить в веб-разделе управления доступом.

Старые алгоритмы включены только в соединении встроенного клиента.
Глобальная конфигурация OpenSSH не меняется. Ключ первого соединения
сохраняется локально; его изменение останавливает вход до отправки пароля.
После смены компьютера/IP разрешённый источник SSH нужно обновить.

## Сборки

Windows: x86_64 (`.exe`). Linux: x86_64, сборка на Ubuntu 22.04
(распакуйте `.tar.gz` и запустите исполняемый файл).
macOS: распакуйте ZIP и откройте приложение `.app`; отдельные arm64 и x86_64 сборки; требования определяет версия macOS
сборочного окружения (14 для arm64, 15 для Intel). Артефакты не подписаны
сертификатом издателя, поэтому ОС может запросить разрешение на запуск.
Для других систем доступен исходный Python-клиент:

```bash
python -m pip install -r desktop/requirements.txt
python g84-setup.py
```

Сборки выполняются GitHub Actions и проходят проверку встроенных ресурсов
и библиотек. Это не заменяет аппаратную проверку каждой ОС/прошивки.
