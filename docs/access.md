# Первый доступ и Python-мастер

`g84-setup.py` — один Python-скрипт со встроенным пакетом для роутера,
расшифровщиком экспорта и веб-интерфейсом. Отдельные `.exe`/`.app` и нативные
сборки не используются. Нужны Python 3.10 или новее и две Python-зависимости;
Bash, OpenSSH, netcat и OpenSSL для мастера не требуются.

```bash
python -m pip install paramiko==3.5.1 cryptography==46.0.3
python g84-setup.py
```

На Windows вместо `python` можно использовать `py -3`, на macOS/Linux — `python3`.
При работе из клонированного репозитория зависимости также можно установить
через `python -m pip install -r requirements.txt`.

Интерфейс открывается в браузере на случайном порту `127.0.0.1`; управление
требует одноразовый токен. После установки зависимостей интернет для настройки
не требуется: интерфейс и пакет находятся внутри скрипта. Пароли остаются в
памяти; резервные копии и SSH-ключи сохраняются локально в каталоге интерфейса.

## Порядок работы

1. Подключитесь к домашней сети. Запустите `python g84-setup.py`.
2. Нажмите «Найти роутер» или введите его локальный IPv4.
3. Укажите пароль веб-интерфейса (обычно пользователь `admin`). Нажмите
   «Подготовить доступ». Альтернатива — импорт экспортированной конфигурации
   либо ввод уже известного пароля superadmin.
4. Проверьте совместимость и установите пакет. При обновлении сохраняются
   пользовательские настройки и списки доменов. По умолчанию перезагрузка отключена.
   Для её выполнения и проверки автозапуска включите соответствующую галочку.

Поиск рассматривает шлюзы и соседей локальной сети, максимум 16 адресов.
Он подтверждает модель по веб-интерфейсу; полного сканирования подсети нет.
При VPN или нестандартной топологии введите адрес вручную.

Когда работа завершена, нажмите «Закрыть мастер», чтобы завершить локальное
приложение и закрыть SSH-соединение.

## Получение superadmin

Метод основан на опубликованном исследовании
[старого экспорта Innbox G84](https://internet-lab.ru/innbox_g84_superadmin).
На поддерживаемой форме мастер входит обычной веб-учётной записью, получает
`config_old_tl.xgi` и разбирает запись superadmin. Старый формат использует
AES-256-CBC с ключом, производным от `InnboxG84`, соли и MD5; совместимость
формата описана в [документации OpenSSL](https://docs.openssl.org/master/man1/openssl-enc/).
Обрабатываются также XML и gzip-экспорты.

Это восстановление пароля из доступного владельцу экспорта, а не универсальный
способ для любой прошивки. Если экспорт отключён, формат изменён или пароль
веб-интерфейса неизвестен, мастер останавливается. Автоматического сброса,
перебора паролей и изменения операторских настроек нет. При временной
блокировке веб-входа нужно дождаться её окончания.

## SSH

Если SSH уже отвечает, настройки доступа не меняются. Для известной формы
[управления доступом G84](https://internet-lab.ru/innbox_g84_ssh) мастер может
добавить SSH на LAN, порт 22, только с IPv4 этого компьютера (/32).
Неизвестная форма или неоднозначная таблица доступа прекращают настройку.
Если запись добавлена, но SSH не отвечает, интерфейс сообщает об этом;
её можно проверить и удалить в веб-разделе управления доступом.

Старые алгоритмы включены только в соединении встроенного клиента.
Глобальная конфигурация OpenSSH не меняется. Ключ первого соединения
сохраняется локально; его изменение останавливает вход до отправки пароля.
После смены компьютера/IP разрешённый источник SSH нужно обновить.

## Подготовка скрипта из исходников

`setup/g84_setup/` содержит исходный код операций и веб-сервера, `setup/ui.html`
— исходный интерфейс. `./scripts/build-payload.sh` собирает пакет и пересоздаёт
самодостаточный `g84-setup.py`. Артефакт запускается без соседних файлов и не
зависит от текущего рабочего каталога. CI проверяет его из отдельной папки,
сверяет встроенный пакет и интерфейс, затем проверяет веб-API.

## Работа с мастером

В списке «Как подключиться» выберите один способ: веб-пароль, файл конфигурации
или известный пароль superadmin. Другие поля не подменяют выбранный способ.
Пароль `admin` автоматически не подставляется. Для файла или SSH-пароля
веб-пароль можно оставить пустым, если SSH уже открыт; иначе он потребуется
для разрешения доступа с этого компьютера.

Справа постоянно указан адрес подключённого G84. Если изменить адрес в форме,
управление блокируется до нового подключения. Отдельно показаны установленная
версия, версия пакета и последнее измерение свободного места.

Обновление страницы сохраняет сессию в этой вкладке и показывает состояние
текущей операции. Если открыть адрес без кода доступа в другой вкладке или
перезапустить скрипт, используйте полную ссылку из терминала. При завершении
самого Python-процесса сессия и пароли в памяти теряются: подключитесь заново.

Сообщения «Выполняется», «Готово» и «Операция не завершена» различаются явно.
Ошибки не исчезают после обновления страницы. Во время операции поля и повторный
запуск заблокированы. «Скачать отчёт без паролей» сохраняет только состояние,
версии и журнал мастера; конфигурация, пароли и код доступа туда не входят.

Если браузер не открылся автоматически, ссылка остаётся в терминале.
